# 가이드 실전 테스트 가이드

비개발자도 따라 할 수 있는 **전체 정산 흐름** 테스트 문서입니다.  
입력값은 엑셀 샘플(`docs/2025년 11월 정산서 양식`)과 동일하며, 앱 자동 계산 테스트(`npm test`)로 검증된 숫자입니다.

---

## Part A — 사전 준비 (1회만)

### A1. 가이드 계정 체크리스트

| # | 확인 항목 | 방법 | 통과 기준 |
|---|-----------|------|-----------|
| 1 | 앱 로그인 | `/login` | 가이드 홈(`/guide`)으로 이동 |
| 2 | 프로필 역할 | Supabase → `profiles` | `role = guide` |
| 3 | 지사 연결 | Supabase → `profiles.branch_id` | **NULL이 아님** (없으면 저장 실패) |
| 4 | 관리자 계정 | 별도 브라우저/시크릿 | `role = admin` 또는 `staff` |

**Supabase에서 가이드 확인 (SQL Editor):**

```sql
SELECT id, email, full_name, role, branch_id
FROM profiles
WHERE email = '여기에_가이드_이메일';
```

`branch_id`가 비어 있으면:

```sql
-- 지사 목록 확인
SELECT id, name FROM branches LIMIT 5;

-- 가이드에 지사 연결 (UUID 교체)
UPDATE profiles SET branch_id = '지사-UUID'
WHERE email = '여기에_가이드_이메일';
```

---

### A2. 테스트 투어 1건 만들기

1. Supabase SQL Editor에서 [`supabase/test_seed.sql`](../supabase/test_seed.sql) 열기  
2. **STEP 1** 실행 → `guide_id`, `branch_id` 복사  
3. **STEP 2** INSERT 주석 해제 후 UUID 붙여넣기 → 실행  
4. 투어 코드 **`TEST-GUIDE-001`** 이 생성되었는지 확인  

> 투어 `start_date`는 **오늘부터 90일 이내**여야 앱에서 선택 가능합니다.  
> seed 파일의 날짜가 오래되면 `2026-05-01` ~ `2026-05-04`처럼 최근 날짜로 수정하세요.

**앱에서 확인:** `/guide/settlements/new` → 투어 선택 목록에 `[TEST-GUIDE-001]` 표시

## Part E — Supabase 빠른 검증

정산 ID 모를 때 (가장 최근 TEST 투어 정산):

```sql
SELECT s.id, s.status, s.created_at, t.tour_code
FROM settlements s
JOIN tours t ON t.id = s.tour_id
WHERE t.tour_code = 'TEST-GUIDE-001'
ORDER BY s.created_at DESC
LIMIT 1;
```

헤더 숫자 확인:

```sql
SELECT exchange_rate, advance_vnd, tour_fee_usd,
       charming_other_usd, tip_received_usd,
       settlement_ratio, megugi_usd, guide_daily_fee_usd
FROM settlements
WHERE id = '위에서_복사한_ID';
```

기대값: `26000`, `5200000`, `120`, `30`, `45`, `0.5`, `3`, `20`

## Part F — 자주 발생하는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| 투어가 선택 목록에 없음 | 90일 지난 날짜 / 이미 정산 있음 | seed 날짜 수정 또는 이전 정산 삭제 |
| 임시저장 실패 "지사 정보" | `branch_id` NULL | Part A1 UPDATE 실행 |
| R85/R87 숫자 다름 | 입력값 하나라도 다름 | Part B 표와 대조 |
| 수정 화면 값이 이상함 | 브라우저 이전 draft | 시크릿 창에서 `/edit` 재시도 |
| 제출 후 수정 불가 | 정상 동작 | `submitted` 상태는 읽기 전용 |
